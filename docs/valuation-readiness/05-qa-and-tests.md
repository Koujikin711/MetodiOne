# QA and Tests Baseline

Цель: снять риск "слабая документация/тесты".

## Минимальный контур тестирования

- Smoke API:
  - `/health`
  - `/health/metrics`
  - `/openapi.json`
- Модульные/контрактные тесты ключевых модулей:
  - analytics
  - finance parsing
  - auth/session critical paths

## Definition of Done (DoD)

- Код ревью пройдено
- Линтер без новых ошибок
- Сборка frontend успешна
- Smoke-тесты backend успешны
- Изменение зафиксировано в changelog/release notes

## Регресс перед релизом

- Авторизация/роли
- CRM этапы и задачи
- Онлайн-запись и журнал
- Аналитика 360
- Финансы и импорты
- Geo-трекер (чекин/чекаут/геозоны/отчеты)

## Метрики качества, которые показываем внешним оценщикам

- % успешных релизов без hotfix
- дефекты на релиз
- среднее время фикса бага
- покрытие smoke/regression сценариев
