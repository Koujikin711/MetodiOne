# Production Metrics Pack

Цель: показать оценщику/инвестору, что продукт наблюдаемый и управляемый в продакшне.

## Что уже внедрено

- Эндпоинт рантайм-метрик: `GET /health/metrics`
- Метрики по API:
  - `total_requests`, `in_flight`
  - `errors_4xx`, `errors_5xx`, `error_rate_pct`
  - latency: `avg_ms`, `p50_ms`, `p95_ms`, `p99_ms`
  - `top_paths` (нагруженные маршруты + их задержки)
- Техническая метка окружения:
  - `extra.build`
  - `extra.db_pool`

## Как снимать baseline

1. Поднять backend и дать 10-15 минут реального трафика.
2. Снять `GET /health/metrics` каждые 60 секунд (минимум 30 точек).
3. Зафиксировать:
   - медиану/95 перцентиль latency
   - error rate
   - топ-5 маршрутов по нагрузке
   - статус пула БД
